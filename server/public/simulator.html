Demo controls

Keyboard: type digits, Enter = Send, Backspace = Cancel, Esc = End.
In menus: 0 = back, 00 = main menu.
Typing a name: the keypad switches to letters like a real phone. Press 2 once for A, twice for B, three times for C. Pause to move on. 0 = space, # = switch ABC / 123 (on any screen), Cancel = delete. You can also type on your computer keyboard.
